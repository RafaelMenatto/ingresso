# 🎟️ Sistema de Compra de Ingressos

Uma aplicação web interativa e intuitiva desenvolvida para simular a seleção e compra de ingressos para diferentes tipos de cadeiras em eventos (Pista, Cadeira Superior e Cadeira Inferior), com controle de estoque em tempo real.

---

## 🚀 Funcionalidades 

- **Seleção do Tipo de Ingressos:** Permite escolher entre diferentes categorias (*Pista*, *Cadeira Superior* e *Cadeira Inferior*).
- **Validação de Quantidade:** Aceita entradas numéricas e impede a compra de quantidades inválidas.
- **Controle de Estoque em Tempo Real:** Atualiza a quantidade disponível para cada setor instantaneamente.
- **Alertas ao Usuário:** Notifica caso o número de ingressos solicitados seja maior do que o estoque disponível.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página web.
- **CSS3:** Estilização moderna e responsiva da interface.
- **JavaScript (ES6+):** Lógica de negócios, manipulação do DOM e gerenciamento das quantidades em estoque.
